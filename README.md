## ECE:4880 at the University of Iowa.
*Members: Nick Millburn, Tyler Purcell, Bashkim Useni*

This is a repository containing the projects for a Senior Design course for ECE undergraduate students.

### [Lab 1: Arduino Temperature Sensor](https://github.com/NickMillburn/SeniorDesign1/tree/main/Lab1)
An Arduino Uno R4 WiFi thermometer with a live web dashboard, two DS18B20 sensors, an OLED display, and threshold-based email alerts.

### [Lab 2: Filter Design & Tone Detection](https://github.com/NickMillburn/SeniorDesign1/tree/main/Lab2)
A digital IIR (biquad) filter on the Arduino Uno R4 WiFi that isolates a target tone from an analog input, drives a real-time detector, and sends timestamped email alerts.

### [Lab 3: Personal Portfolio Website](https://github.com/NickMillburn/SeniorDesign1/tree/main/Lab3)
A Next.js 15 + React 19 + Tailwind CSS portfolio website starter template.
